# agent/ — (future) procurement-optimisation agent

**Not implemented yet — placeholder for the planned AI optimisation layer.**

The current version intentionally contains no AI. Demand is generated by predefined stochastic
processes and procurement weights are configured by hand or explored with `calibration/sweep.py`.

The future agent (spec §22) will:

1. Observe historical simulation data (`engine/events.py`, `/api/export`).
2. Learn which procurement-weight configurations maximise **long-term P&L**.
3. Later, forecast demand spikes and pre-position inventory.

Feedback loop:

    historical data → agent → procurement-parameter optimisation
        → procurement engine → simulation → P&L feedback ↺

`calibration/sweep.py` already emits the `(parameter set → long-term P&L)` signal the agent will
learn from; the dashboard's **Strategy Lab** is a brute-force stand-in for the optimiser.
